# WhatsApp 助手（Tampermonkey 用户脚本）

在 WhatsApp Business 网页版上提供：中外文自动翻译、AI 客户分析与回复建议、独立 AI 助手、PI 形式发票（英文 / 西语 PDF）生成、网页语音通话同声传译（默认关闭）。

- 安装 / 更新：在装了 Tampermonkey 的 Chrome 里打开
  https://raw.githubusercontent.com/wangsiyuan4124-cloud/whatsapp-assistant/main/whatsapp-assistant.user.js
- 开发交接说明：见 [HANDOFF.md](HANDOFF.md)
- 测试：`cd tests && npm install && npx playwright install chromium && npm test`

注意：本仓库公开，API Key、银行信息、公章、Logo 只保存在使用者浏览器的插件设置里，不要提交到仓库。

## 通话同传

Leo 用 WhatsApp 网页版给海外客户打语音。打开工具栏上的「通话同传」之后：

- 客户说英语、西语或法语，页面上方出中文字幕（可以选择同时看原文）。
- Leo 说中文，插件把话译成客户的语言并合成声音，用这条声音替换送给对方的麦克风。客户不用看手机，也不用装任何东西。
- 客户听到的语言默认跟着刚才识别到的语言，浮层里可以改成固定英语 / 西语 / 法语。
- 可以让 Leo 的原声以很小的音量垫在译文下面。设成 0 就是只听译文。翻译服务一断，立刻改回原声，避免对方听成静音。
- 听音可以在浮层里随时换。**耳机模式**是默认：您的话一直送去翻译，请戴耳机。**外放模式**给安静、不戴耳机的房间。

没打开这个开关时，文字翻译、客户分析、PI、车型资料和以前一样。账号如果没有 WhatsApp 网页通话，浮层会一直写「未检测到 WhatsApp 通话」。

### 设置

⚙ →「通话同传」。

1. 部署 [call-relay](call-relay/README.md)（一个很小的 Node 服务）。插件里填中转地址和中转密钥。用默认的阿里云引擎时，**双方的语音都会经过这台中转服务器**，再送到阿里云（北京）；阿里云长期 Key 只放在服务器上。用 OpenAI 引擎时，中转只负责换一个短时密钥，语音直接连 OpenAI，不经过中转。
2. 只用 OpenAI、又没有服务器时，也可以把 OpenAI Key 直接填在插件里。它和 DeepSeek Key 一样，只存在这台浏览器里，不要写进仓库。阿里云没有这种用法，必须走中转。
3. 点「测试连接」。成功只说明密钥能换到，不代表这则通话已经通。

### 选哪个引擎

默认是**阿里云百炼**，模型 `qwen3.8-livetranslate-flash-realtime`，地域华北 2（北京）。OpenAI 仍可在「设置 → 通话同传」的两个下拉框里改回去，等以后能付款再用。

| 方向 | 阿里云（默认） | OpenAI（可选） |
|---|---|---|
| 我说话，译给客户听 | 文字 + 译音，流式送进通话 | 同声传译，或「带术语表」（稍慢） |
| 对方说话，给我看字幕 | 只出文字，不生成译音，省钱 | 转写再翻译，或同声传译 |

术语来自「通话术语」和「基本设置」里的翻译术语表，会交给阿里云的 `translation.corpus.phrases`（最多 1000 条）。写成 `中文 = 英文 | 西语 | 法语` 时，第三段只给通话用。车型名这种中外文一样的词会原样保留。

阿里云长期 Key **不能**写进插件。插件只填中转地址。Key 和业务空间 ID 放在你自己的服务器上，见 [call-relay](call-relay/README.md)。浏览器连的是你的中转；中转再带密钥去连北京的百炼。静音太久如果被服务端断开（约 60 秒没有有效语音），插件会自动重连，不用你动手。

### 开通阿里云百炼

1. 用阿里云账号登录，完成实名认证。
2. 打开[百炼 / 模型服务平台 Model Studio](https://bailian.console.aliyun.com/)，地域选**华北 2（北京）**。
3. 开通百炼，并确认能用 `qwen3.8-livetranslate-flash-realtime`（实时音视频翻译）。
4. 在密钥管理里创建 API Key，记下**业务空间 ID**（WorkspaceId，域名里那一截）。
5. 新用户控制台通常有免费额度（常见是 **100 万 Token / 90 天**，以你账号页面上的数字为准）。把「免费额度用完即停」打开，避免静默开始扣费。
6. 在你已有的云服务器上跑 `call-relay`（旁边已经有 Java 和数据库也没关系，这是一个单独的小 Node 进程，不用数据库）。

### 费用（北京标价，2026-11 文档，以控制台为准）

百炼按 Token，不是按分钟一口价：

- 音频输入 40 元 / 百万 Token
- 文本输出 100 元 / 百万 Token
- 音频输出 160 元 / 百万 Token

默认通话：你和客户两边都有音频输入；只有你说的话会生成译音，客户那边只出中文字幕、不生成语音。免费额度用完之后才按上表计费。OpenAI 同声传译大约 $0.034 / 分钟，转写大约 $0.017 / 分钟，国内付款不方便，所以不是默认。

术语来自两项：这一页的「通话术语」（每行一个专名，如 Chery、R8、瑞虎），以及「基本设置」里原来的翻译术语表。写成 `中文 = 英文 | 西语 | 法语` 时，第三段只给通话用，不改变原来的文字翻译。

### 改用 OpenAI 时的费用（2026-11 官网价，以 OpenAI 当时页面为准）

- 同声传译大约 **$0.034 / 分钟**音频。
- 转写大约 **$0.017 / 分钟**。
- 我方同声传译 + 对方转写大约 **$0.05 / 分钟**，一小时约 3 美元。两边都用同声传译时一小时约 4 美元。
- 「带术语表」走的是实时语音会话，通常不低于同声传译，以账单为准。
- 临时密钥本身不按分钟计费；开始送声音之后才计。

### 延迟

目标是 Leo 一句话说完后，大约 1 秒内客户听到译文。实际还取决于网络和当次模型速度。

- 同声传译是边说边出的，不看「句尾停顿」。
- 「句尾停顿」默认 400 毫秒。阿里云把它交给服务端 VAD；OpenAI「带术语表」和转写也会用这个数。调到 300 更快，但容易把一句话切成两截；调到 600 更稳、更慢。范围 200–800。阿里云同声传译仍会边说边出字，不必等整句结束。
- 原声混入默认 15（百分制）。0 表示句和句之间客户可能短暂听不到声音，这是只出译文的正常空隙，不是故障。浮层如果写「已改回您的原声」，那才是翻译断了。

### 耳机模式和外放模式

浮层上的「听音」可以每次通话改，设置里的选项会被记住。

- **耳机模式**：和第一版一样。麦克风一直送去翻译，译文和压低的原声一起送给客户。请戴耳机。
- **外放模式**：房间安静、不戴耳机时用。浏览器会给麦克风打开回声消除和降噪。对方一开始出声，您的麦克风就不再送进翻译（扬声器里的声音不会被当成您的话再翻一遍），同时暂时不把您的原声送回去，避免客户听到自己的回声。对方停口后默认再等 400 毫秒（可改 200–800）。这段过去之后，要等您开口，才重新把麦克风送去翻译。对方的中文始终只显示在您的屏幕上，不从扬声器放出来。
- 外放有两个音量门槛，都在设置里：把对方当成「正在说话」（默认 0.02），把您当成「开始说话」（默认 0.03）。底噪大就把第二个调高；对方声音小、掐得太晚就把第一个调低。

外放不能代替耳机。旁边有人说话、电视开着，仍可能被送去翻译。能戴耳机就用耳机模式。

### 怎么试

1. Tampermonkey 更新脚本后刷新 WhatsApp。第一次安装如果通话没被钩住，再刷新一次（PDF 库要先下载，可能让钩子来晚）。
2. 在中转服务器配好阿里云 Key 和业务空间，插件里填中转地址，点测试连接。要用 OpenAI 再在引擎下拉框里改。
3. 勾上「通话同传」。戴耳机就用浮层里的「耳机模式」；安静房间不戴耳机就选「外放模式」。
4. 用**网页版**发起语音通话（手机上打的电话这里看不到）。
5. 浮层应从「未检测到 WhatsApp 通话」变成「正在连接翻译…」，再变成「同传中」。
6. 说一句中文，客户应听到外语，浮层「客户听到」出现译文。客户说英语、西语或法语，上方出现中文。
7. 关掉开关再说话，客户只听到原声。文字翻译的回车发送应和以前一样。

开发机上的自动测试（不打真电话）：`cd tests && npm test`，其中 `t14-call-interpret.js` 检查开关关闭时音轨原样送出、打开后换成混音、翻译一断就改回原声。
