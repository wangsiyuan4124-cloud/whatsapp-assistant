# WhatsApp 助手（Tampermonkey 用户脚本）

在 WhatsApp Business 网页版上提供：中外文自动翻译、AI 客户分析与回复建议、独立 AI 助手、PI 形式发票（英文 / 西语 PDF）生成、网页语音通话同声传译（默认关闭）。

- 安装 / 更新：在装了 Tampermonkey 的 Chrome 里打开
  https://raw.githubusercontent.com/wangsiyuan4124-cloud/whatsapp-assistant/main/whatsapp-assistant.user.js
- 开发交接说明：见 [HANDOFF.md](HANDOFF.md)
- 测试：`cd tests && npm install && npx playwright install chromium && npm test`

注意：本仓库公开，API Key、银行信息、公章、Logo 只保存在使用者浏览器的插件设置里，不要提交到仓库。

## 通话同传

Leo 用 WhatsApp 网页版给海外客户打语音。打开工具栏上的「通话同传」之后：

- 客户说英语、西语或法语，页面上方出中文字幕（可以选择同时看原文）。
- Leo 说中文，插件把话译成客户的语言并合成声音，用这条声音替换送给对方的麦克风。客户不用看手机，也不用装任何东西。
- 客户听到的语言默认跟着刚才识别到的语言，浮层里可以改成固定英语 / 西语 / 法语。
- 可以让 Leo 的原声以很小的音量垫在译文下面。设成 0 就是只听译文。翻译服务一断，立刻改回原声，避免对方听成静音。
- **请戴耳机。** 用扬声器时，放出的声音会被麦克风收进去再翻一遍。

没打开这个开关时，文字翻译、客户分析、PI、车型资料和以前一样。账号如果没有 WhatsApp 网页通话，浮层会一直写「未检测到 WhatsApp 通话」。

### 设置

⚙ →「通话同传」。

1. 推荐部署 [call-relay](call-relay/README.md)（一个很小的 Node 服务）。插件里填中转地址和中转密钥，OpenAI 主 Key 只放在服务器上。中转只负责换一个短时密钥，语音不经过它。
2. 没有服务器时，也可以把 OpenAI Key 直接填在插件里。它和 DeepSeek Key 一样，只存在这台浏览器里，不要写进仓库。
3. 点「测试连接」。成功只说明密钥能换到，不代表这则通话已经通。

### 选哪个引擎

| 方向 | 默认 | 什么时候换 |
|---|---|---|
| 我说话，译给客户听 | 同声传译（`gpt-realtime-translate`） | 车型名必须按术语表读时，改成「带术语表」。它要等一句说完再开口，大约慢半秒。同声传译模型本身不接受自定义术语。 |
| 对方说话，给我看字幕 | 转写再翻译（`gpt-live-transcribe` + 原来的谷歌/微软） | 字幕想更顺，改成同声传译。更贵。 |

术语来自两项：这一页的「通话术语」（每行一个专名，如 Chery、R8、瑞虎），以及「基本设置」里原来的翻译术语表。写成 `中文 = 英文 | 西语 | 法语` 时，第三段只给通话用，不改变原来的文字翻译。

### 费用（2026-11 官网价，以 OpenAI 当时页面为准）

- 同声传译大约 **$0.034 / 分钟**音频。
- 转写大约 **$0.017 / 分钟**。
- 默认（我方同声传译 + 对方转写）大约 **$0.05 / 分钟**，一小时约 3 美元。两边都用同声传译时一小时约 4 美元。
- 「带术语表」走的是实时语音会话，通常不低于同声传译，以账单为准。
- 临时密钥本身不按分钟计费；开始送声音之后才计。

### 延迟

目标是 Leo 一句话说完后，大约 1 秒内客户听到译文。实际还取决于网络和当次模型速度。

- 同声传译是边说边出的，不看「句尾停顿」。
- 「句尾停顿」默认 400 毫秒，只影响「带术语表」和「转写再翻译」。调到 300 更快，但容易把一句话切成两截；调到 600 更稳、更慢。范围 200–800。
- 原声混入默认 15（百分制）。0 表示句和句之间客户可能短暂听不到声音，这是只出译文的正常空隙，不是故障。浮层如果写「已改回您的原声」，那才是翻译断了。

### 怎么试

1. Tampermonkey 更新脚本后刷新 WhatsApp。第一次安装如果通话没被钩住，再刷新一次（PDF 库要先下载，可能让钩子来晚）。
2. 填好中转或 Key，点测试连接。
3. 戴上耳机，勾上「通话同传」。
4. 用**网页版**发起语音通话（手机上打的电话这里看不到）。
5. 浮层应从「未检测到 WhatsApp 通话」变成「正在连接翻译…」，再变成「同传中」。
6. 说一句中文，客户应听到外语，浮层「客户听到」出现译文。客户说英语、西语或法语，上方出现中文。
7. 关掉开关再说话，客户只听到原声。文字翻译的回车发送应和以前一样。

开发机上的自动测试（不打真电话）：`cd tests && npm test`，其中 `t14-call-interpret.js` 检查开关关闭时音轨原样送出、打开后换成混音、翻译一断就改回原声。
